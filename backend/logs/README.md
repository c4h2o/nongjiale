# 日志文件说明

## 日志文件类型

### error.log
- 记录所有错误级别的日志
- 包含错误堆栈信息
- 用于问题排查和调试

### combined.log
- 记录所有级别的日志
- 包含请求日志、业务日志等
- 用于系统监控和分析

## 日志级别

- `error` - 错误信息
- `warn` - 警告信息
- `info` - 一般信息
- `debug` - 调试信息

## 日志格式

```json
{
  "timestamp": "2024-01-02 10:30:45",
  "level": "info",
  "message": "用户登录成功",
  "service": "smart-garden-api",
  "userId": "user-id-123",
  "ip": "192.168.1.100"
}
```

## 日志轮转

- 单个日志文件最大5MB
- 保留最近5个日志文件
- 自动压缩旧日志文件

## 注意事项

1. 生产环境不要记录敏感信息（密码、token等）
2. 定期清理过期日志文件
3. 监控日志文件大小，避免磁盘空间不足
