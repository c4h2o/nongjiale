# 图片资源说明

## 图标文件列表

### 底部导航图标
- `home.png` / `home-active.png` - 首页图标
- `garden.png` / `garden-active.png` - 我的菜园图标  
- `service.png` / `service-active.png` - 服务图标
- `profile.png` / `profile-active.png` - 我的图标

### 功能图标
- `logo.png` - 应用Logo
- `wechat.png` - 微信登录图标
- `add.png` - 添加图标
- `monitor.png` - 监控图标
- `control.png` - 控制图标

### 大图标
- `garden-large.png` - 菜园大图标
- `service-large.png` - 服务大图标
- `promotion-large.png` - 推广大图标

### 空状态图片
- `empty-garden.png` - 空菜园状态图片

## 图标规格要求

### 底部导航图标
- 尺寸：81px × 81px
- 格式：PNG
- 背景：透明

### 功能图标
- 尺寸：48px × 48px 或 64px × 64px
- 格式：PNG
- 背景：透明

### 应用Logo
- 尺寸：128px × 128px
- 格式：PNG
- 背景：透明或白色

### 大图标
- 尺寸：120px × 120px
- 格式：PNG
- 背景：透明

### 空状态图片
- 尺寸：200px × 200px
- 格式：PNG
- 背景：透明

## 设计风格

- 采用扁平化设计风格
- 主色调：#4CAF50（绿色）
- 辅助色：#81C784（浅绿色）
- 图标线条粗细：2px
- 圆角半径：4px

## 注意事项

1. 所有图标需要提供普通和高亮两个版本
2. 图标需要适配不同屏幕密度
3. 建议使用SVG格式的矢量图标，然后导出为PNG
4. 确保图标在深色和浅色背景下都清晰可见
