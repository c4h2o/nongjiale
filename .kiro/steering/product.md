# Product Overview

## 智慧共享菜园微信小程序

A WeChat Mini Program for IoT-enabled shared garden management, targeting rapid deployment as an engineering prototype focused on the "shared garden" core scenario.

### Target Users
- **C-end users**: Individuals who want to own a garden
- **B-end users**: Users with land/restaurants who have garden space

### Core Capabilities
1. **Remote Garden Monitoring**: Real-time visual monitoring with ≥720P resolution, ≤3s latency
2. **Remote Irrigation Control**: 5/10/15 minute irrigation options with real-time device status sync
3. **Agricultural Service Booking**: 5 core service types with order management
4. **Promotion & Referral System**: Promotion code generation and role-based user acquisition

### Performance Requirements
- Page load time: First screen ≤3s, subsequent pages ≤1.5s
- Camera feed latency: ≤3s
- Concurrent users: ≤100 simultaneous online users
- Operation response time: ≤1s

### Compatibility
- WeChat Mini Program base library: ≥2.30.0
- Device support: Mainstream phone sizes
- System compatibility: iOS/Android
- Network environments: 4G/5G/WiFi with 2G optimization
